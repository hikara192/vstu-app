# Политика конфиденциальности приложения «VSTU HOME»

**Дата вступления в силу: 16 октября 2026 г.**

Настоящая Политика описывает, какие данные обрабатывает мобильное приложение **«VSTU HOME»** (далее — «Приложение»), как и зачем эти данные используются, где хранятся и как пользователь может ими управлять.

Приложение является справочно-учебным сервисом для студентов и сотрудников Витебского государственного технического университета (ВГТУ) и не предназначено для коммерческой рекламы или продажи данных.

Используя Приложение, вы подтверждаете, что ознакомились с настоящей Политикой.

## 2. Какие данные обрабатываются

### 2.1. Данные, которые вы передаёте добровольно

| Данные | Зачем | Где хранятся |
|---|---|---|
| Логин и пароль от СДО ВГТУ | Для входа в систему дистанционного обучения (передача на сервер `sdo.vstu.by` для получения токена) | **Не сохраняются** в Приложении — используются только при входе и не хранятся после получения токена |
| Файлы, которые вы выбираете для сдачи заданий | Загрузка работ в СДО (Moodle) | Передаются напрямую на сервер СДО ВГТУ |

### 2.2. Данные, которые Приложение создаёт и хранит на вашем устройстве

| Данные | Зачем | Где хранятся |
|---|---|---|
| Выбранная группа (идентификатор и название) | Чтобы открывать расписание нужной группы | Локальное хранилище приложения (`SharedPreferences`) |
| Кэш расписания и списка групп | Работа Приложения без интернета и меньше запросов к серверу | Локальное хранилище приложения |
| Настройки оформления: тема, цвет акцента, стартовый экран, включены ли уведомления | Сохранение ваших настроек | Локальное хранилище приложения |
| Токен веб-сервиса СДО (Moodle `wstoken`), профиль пользователя (ID, имя, отображаемое имя, аватар) | Чтобы не вводить пароль при каждом открытии СДО | **Зашифрованное** хранилище (`flutter_secure_storage`: на Android — AES-Keystore) |
| Куки веб-сессии СДО (`MoodleSession`) | Чтобы открывать страницы СДО без повторного входа | **Зашифрованное** хранилище (`flutter_secure_storage`) |
| Скачанные файлы курсов и вложения | Просмотр материалов офлайн | Локальный кэш приложения |
| Локальные уведомления о парах (напоминания) | Напоминание о начале занятий | Локально на устройстве; данные не отправляются в сеть |

### 2.3. Данные, которые Приложение НЕ собирает

Приложение **не** собирает и не передаёт:

- данные для аналитики и статистики использования;
- идентификаторы рекламы, данные для поведенческой рекламы;
- геолокацию, контакты, доступ к камере, микрофону, SMS и т.п.;
- номер телефона, данные банковских карт (приложение не содержит платежей);
- данные о социальных сетях;
- какие-либо данные третьим компаниям для их собственных целей.

В Приложении нет рекламных SDK, SDK аналитики (Firebase Analytics, Amplitude и аналогов) и трекеров.

## 3. С какими серверами работает Приложение

Приложение отправляет сетевые запросы только к двум сервисам:

1. **Сервис расписания** — `https://schedule.vstu.by/api/v1`
   - запрос списка групп и расписания (по идентификатору группы);
   - передаётся только идентификатор группы, никаких персональных данных.

2. **Система дистанционного обучения (СДО) ВГТУ** — `https://sdo.vstu.by`
   - обмен логина/пароля на токен, вызовы веб-сервисов Moodle (курсы, задания, оценки, календарь);
   - скачивание и загрузка файлов материалов и работ.

Приложение проверяет, что ссылки на файлы и адреса запросов ведут на домены ВГТУ (`vstu.by`), и не передаёт секреты (токен, куки) на сторонние ресурсы.

## 4. Для чего используются данные

- предоставление функций Приложения: расписание, список групп, материалы СДО, сдача заданий;
- сохранение ваших настроек и состояния входа в СДО между запусками;
- отправка локальных напоминаний о занятиях;
- обеспечение безопасности: защита токенов и сессий от чтения другими приложениями.

**Правовые основания:** выполнение договора (предоставление сервиса расписания и доступа к СДО) и законный интерес в поддержании работоспособности и безопасности Приложения.

## 5. Передача данных третьим лицам

Приложение **не продаёт, не сдаёт в аренду и не передаёт** персональные данные третьим лицам, за исключением случаев:

- данные передаются напрямую серверам ВГТУ (`schedule.vstu.by`, `sdo.vstu.by`) — это необходимо для работы Приложения;
- раскрытие данных требуется по требованию закона, компетентных органов в установленном порядке.

Приложение не содержит встроенной рекламы и не работает с внешними рекламными или аналитическими сетями.

## 6. Безопасность

- токен СДО, профиль и куки сессии хранятся в зашифрованном хранилище (`flutter_secure_storage`, шифрование AES через Android Keystore);
- пароль от СДО не сохраняется на устройстве;
- запросы к СДО идут только по HTTPS;
- ссылки на файлы проверяются на принадлежность доменам ВГТУ;
- Приложение работает офлайн: часть данных доступна из локального кэша без выхода в сеть.

Обратите внимание: безопасность приложений общедоступных магазинов не обеспечивается на 100%; не передавайте свой пароль от СДО третьим лицам и не используйте Приложение на чужих устройствах без выхода из аккаунта.

## 7. Хранение и удаление данных

- Данные хранятся на вашем устройстве до тех пор, пока вы не очистите их.
- Удалить данные можно так:
  - **выход из СДО** в настройках Приложения — удаляется токен, профиль и куки сессии;
  - **«Очистить кэш/данные»** в настройках Android (Приложение → Хранилище) — удаляются все локальные данные, включая кэш расписания и настройки.
- При удалении Приложения все локальные данные удаляются вместе с ним.
- Данные на серверах СДО и сервиса расписания хранятся в соответствии с правилами ВГТУ; для их удаления обращайтесь в службу поддержки университета.

## 8. Данные несовершеннолетних

Приложение предназначено для студентов и сотрудников университета. Сознательно обрабатывать данные лиц младше 18 лет Приложение не стремится. Если вы считаете, что ребенок передал Приложению персональные данные без согласия законного представителя, напишите нам — данные будут удалены.
