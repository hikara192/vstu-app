# VSTU HOME

Мобильное приложение для студентов и сотрудников ВГТУ: расписание занятий, список групп, доступ к СДО (Moodle) с телефона.

## Приложение

- `mobile/` — исходный код мобильного приложения (Flutter, Android).

## Документы

- [Политика конфиденциальности](https://hikara192.github.io/vstu-app/) — онлайн-версия (GitHub Pages).
- [Политика конфиденциальности (Markdown)](PRIVACY_POLICY.md) — исходный текст.

## Конфиденциальность в двух строках

Приложение не собирает аналитику и не показывает рекламу. На устройстве хранятся только выбранная группа, настройки, кэш расписания и (в зашифрованном виде через `flutter_secure_storage`) данные входа в СДО ВГТУ. Данные не продаются и не передаются третьим лицам.
